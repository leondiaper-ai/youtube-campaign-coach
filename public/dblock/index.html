Analysis

How this was measured

Every figure in this deck comes from public sources, pulled on 15 September 2026. The full evidence trail, including what we tested and rejected, sits in the internal audit.

Sources

  • Public YouTube Data API — full catalogue, all 197 public videos, not sampled
  • Public channel and playlist surfaces
  • Watcher weekly snapshots of the same public API
  • Public comment sample — qualitative
  • Verified YouTube product documentation

What public data can't tell us

  • No YouTube Studio metrics are used anywhere: no impressions, click-through rate, retention, traffic sources or unique viewers
  • Views are plays, not people — no per-viewer claim is made
  • Subscriber counts are rounded by YouTube to three significant figures
  • Shorts and long-form views are not equivalent units and are never compared directly

Things to confirm before acting

  • Whether Collaboration credits can be applied to already-published videos — documented for the upload flow only
  • GRM-hosted videos would need GRM Daily to initiate any collaboration
  • Stations is invite-only with no published eligibility or application route — it is a question, not a plan
  • A meaningful share of lifetime channel views isn't attributable to any currently-public video; Studio should resolve it
