Analysis

How this was measured

Sources

  • Public YouTube Data API — the complete 198-video catalogue, not a sample
  • Public channel, playlist and Topic-channel surfaces
  • A 15-channel UK rap comparison set, each pulled in full
  • Public comment samples, read qualitatively
  • Verified YouTube product documentation

How the comparison works

  • Channels are compared on behaviour — months with an upload, upload counts, longest silence — never on view totals, which aren't like-for-like across channels
  • "Active month" = at least one public upload in that calendar month
  • A video counts as having a second asset only if another upload exists for the same song
  • Worldwide Wave demand uses art-track views, all uploaded the same day, so they're directly comparable

What public data can't show

  • No YouTube Studio metrics are used anywhere: no impressions, click-through rate, retention, traffic sources or unique viewers
  • Views are plays, not people
  • Subscriber counts are rounded by YouTube
  • Shorts and long-form views aren't equivalent units and are never compared
  • Cumulative view counts can't show what a video is doing today — only across its life

Worth confirming together

  • D-Block Europe TV. The programming idea is built entirely from the existing catalogue — 198 owned videos across ten years — so it needs no new production. What isn't established is the product: YouTube's Stations is currently an invite-only pilot with no published eligibility criteria and no application route, so this is a conversation to have with YouTube rather than a feature we can switch on. The idea stands either way; a playlist-and-shelf version of it is available today
  • How far collaboration credits reach into already-published videos
  • Whether the archive footage Young Adz has described exists in usable form
  • What Studio shows about where subscribers actually come from
  • Worldwide Wave's chart registration — it's absent from the Top 100 in release week, which is unusual enough to be worth a question
