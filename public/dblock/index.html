Analysis

How this was put together

Everything here comes from public sources, pulled on 15 September 2026 — the full channel catalogue, all 197 videos, not a sample.

Sources

  • Public YouTube Data API — the complete catalogue
  • Public channel and playlist surfaces
  • Weekly snapshots of the same public API
  • A public comment sample, read qualitatively
  • Verified YouTube product documentation

What public data doesn't show

  • No YouTube Studio metrics are used anywhere: no impressions, click-through rate, retention, traffic sources or unique viewers
  • Views are plays, not people — no per-viewer claim is made
  • Subscriber counts are rounded by YouTube to three significant figures
  • Shorts and long-form views aren't equivalent units, so they're never compared directly
  • The comment sample shows what the loudest conversation is about, not what most people think

Worth confirming together

  • How far collaboration credits can reach into already-published videos
  • Historic videos hosted by GRM Daily would need GRM to take part
  • Stations is invite-only with no published route — a question for YouTube, not a plan
  • A share of lifetime channel views isn't attributable to any currently-public video; Studio would explain it
