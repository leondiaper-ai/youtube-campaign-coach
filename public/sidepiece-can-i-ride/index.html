05 · The multi-format lesson

One record. Several ways to discover the artist.

What Defected demonstrates

In the prior Edge Of Desire audit, the release was connected across official audio, lyric, live performance, remixes and Shorts. The value is in linking complementary formats, not hitting a video quota.

How that applies here

Discover: creator-led Shorts and existing dance/social behaviour.

Recognise: SIDEPIECE joining the trend or performing the song live.

Continue: the OMV and existing relevant supporting assets.

Only build connections between real assets. A playlist or related-video link cannot replace compelling creative.

Strategic comparison with the existing Defected deep dive. No measured uplift is attributed to the format mix.
